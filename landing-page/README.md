# Quint Landing Page

Static landing page prepared for Vercel deployment.

## Local Preview

```bash
npm run start
```

Then open:

```text
http://localhost:3000
```

## Deploy To Vercel

From this folder:

```bash
npm install
npx vercel
```

For production:

```bash
npx vercel --prod
```

If importing through the Vercel dashboard, set the project root to this
`landing-page` folder. No framework preset is needed.
